# ПР-9. Распределение памяти (вариант B)

Запуск (Python 3, для графика нужен matplotlib):

    python3 run_ops1.py first          # карта памяти, ops1, без слияния
    python3 run_ops1.py first merge    # то же со слиянием свободных блоков
    python3 run_buddy1.py              # buddy system на ops1, лог разбиений и слияний
    python3 compare.py                 # сравнение на ops2, таблица и compare.png

## Три стратегии на ops1 (память 1024, без слияния)

| Стратегия | Отказы (операции) | Свободно | Макс. дыра | Дыр |
|---|---|---|---|---|
| first fit | 3 (8, 10, 12) | 904 | 250 | 5 |
| best fit  | 2 (10, 12)    | 624 | 250 | 5 |
| worst fit | 3 (8, 10, 12) | 904 | 250 | 5 |

## Операция 8 (first fit): почему отказ

Запрос alloc P6 280 отклонён, хотя суммарно свободно 554 единицы (180 + 250 + 124),
то есть больше 280. Но свободная память разбита на три дыры, и самая большая из них
250 < 280, поэтому непрерывного блока нужного размера нет.

Это явление называется **внешняя фрагментация**: свободной памяти достаточно,
но она раздроблена на несвязные дыры. Слияние соседних свободных блоков (coalescing)
помогает только там, где дыры соседние.

## Слияние (coalescing) на ops2

| Подход | Отказов | Внешняя фр. | Внутр., ср. |
|---|---|---|---|
| first | 50 | 0.78 | 0 |
| best | 45 | 0.73 | 0 |
| worst | 61 | 0.87 | 0 |
| first + merge | 33 | 0.47 | 0 |
| best + merge | 32 | 0.36 | 0 |
| worst + merge | 38 | 0.52 | 0 |
| buddy | 38 | 0.36 | 175 |

Слияние соседних свободных блоков при free резко снижает число отказов
и внешнюю фрагментацию. График: `compare.png`.

Внешняя фрагментация = 1 − (самая большая дыра / вся свободная память), среднее по 200 шагам.

## Чем платит buddy system

Buddy снижает внешнюю фрагментацию до уровня best fit (0.36), но платит
внутренней фрагментацией: запрос округляется вверх до степени двойки
(например, 130 получает блок 256), и остаток блока пропадает.
В среднем это 175 единиц, около 17% памяти. Внешняя фрагментация при этом
не исчезает полностью: сливаются только «приятели», а соседние свободные блоки
из разных пар не объединяются.

## Контрольные вопросы

1. Worst fit берёт самую большую дыру, чтобы остаток тоже был крупным и пригодным
   для следующих запросов, а не мелким огрызком, как у best fit. На практике на ops2
   он дал больше отказов (61 против 45 у best fit без слияния).
2. Buddy порождает внутреннюю фрагментацию из-за округления до степени двойки,
   а также остаточную внешнюю, потому что сливаются только «приятели».
